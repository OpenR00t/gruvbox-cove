# Fonts

Gruvbox Cove uses one type family everywhere:

- **CaskaydiaCove Nerd Font** (Cascadia Code with Nerd Font icons) for interface, headings and code. Get it from
  [Nerd Fonts](https://www.nerdfonts.com/font-downloads); this repo doesn't redistribute it.
- **[Cove Sans](cove-sans/)**, a proportional re-spacing of CaskaydiaCove, for prose. Same letter shapes, so long text
  keeps the mono font's look. The themes use the **SemiLight** weight for body text.

`scripts/` holds the build (`build_cove.py`, FontForge) and the specimen renderer. `specimens/` has the family sheet
and a before/after of the spacing fixes. `licenses/` has the license of the source font.
