# Font scripts

- `build_cove.py`: builds one Cove Sans style from the matching CaskaydiaCove Nerd Font style. Needs FontForge's Python
  module (e.g. `apt install python3-fontforge`, run with that Python).
- `cove_specimen.py`: renders `../specimens/cove-sans-family.png`. Needs Pillow with RAQM.

Both are AGPL-3.0-or-later; the fonts they produce stay under the SIL Open Font License.
